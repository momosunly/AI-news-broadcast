今日核心摘要

模型进展

Google 发布 Gemini 3.8 Flash 与 3.8 Flash Cyber

Google 2026-09-02 宣布 Gemini 3.8 Flash，强调长程软件工程、Agent 工作流和复杂推理；开发者文档显示模型支持 1,048,576 输入 token、65,536 输出 token、代码执行、计算机使用预览、文件搜索和 Search grounding。Cyber 版本通过 Fairwind Program 面向可信防御者开放。Google 博客 / Gemini API 文档

安全与伦理

OpenAI Astra 的“Critical”网络安全能力成为监管焦点

OpenAI 8 月已披露 Astra 内部评估触及 Preparedness Framework 下的 critical cyber 能力，Axios 2026-09-03 报道称 Sam Altman 认可美国政府对高级模型的自愿审查流程；WSJ 和 The Verge 则强调其受限发布、安全监控与可解释性争议。事实：OpenAI 已确认不能排除 critical cyber 能力；判断：Astra 会把“发布前政府审查”推成事实标准。OpenAI / Axios

模型进展

Anthropic 推 Claude Fable 5.1 / Mythos 5.1

Anthropic 2026-09-01 发布 Fable 5.1 和 Mythos 5.1。Fable 5.1 面向编码、知识工作、长程 Agent 和企业流程，缓存读取价格降至每百万 token 0.25 美元，典型工作负载成本估计下降 25%，高度 Agent 任务最多下降约 45%；Mythos 5.1 继续限制给经审核的网络防御和生命科学组织。Fable / Mythos

模型进展

Meta Muse Spark 1.3 强化编码与 Agent 工作流

Meta AI Research 2026-09-02 发布 Muse Spark 1.3，官方称其在 Agentic workflows、Coding、抗 prompt injection、不可逆操作判断等方面增强，并上线 Muse Code 与 Meta Model API。Meta 仍在追赶 OpenAI、Anthropic、Google，但把“个人超级智能”落脚到编码与多工作流执行。Meta AI Research

中国大模型

阿里百炼上架 qwen3.8-max-0902，腾讯混元 Hy4 preview 进入迁移窗口

阿里云百炼模型表显示 2026-09-02 上架 qwen3.8-max-0902，覆盖北京、新加坡、美国弗吉尼亚等部署范围，强调编码、协作智能体、视觉理解和 100 万上下文。腾讯云公告要求混元旧版图像/视频/3D 接口在 2026-09-30 前迁移至 TokenHub，新版 HY-Image-3.0、HY-Video-1.5、HY-3D-3.1 被列为替代。阿里云百炼 / 腾讯云公告

中国大模型

Hugging Face 模型卡显示 GLM-5.3-Flash 为 320B 总参数、18B 激活参数、MIT 许可、原生多模态并支持长上下文；腾讯 2026-08-28 发布并开源 Hy4 preview，总参数 770B、激活 49B、上下文突破 1M，接入 WorkBuddy、CodeBuddy、元宝、ima、腾讯云 TokenHub 和 OpenRouter。GLM-5.3-Flash / 腾讯

AI 资讯分类

模型进展
  • 长程 Agent 成为共同主线：Gemini 3.8 Flash、Claude Fable 5.1、Meta Muse Spark 1.3、Qwen3.8-Max-0902、Hy4 preview、GLM-5.3-Flash 都在强调编码、工具调用、持续执行、长上下文和多模态任务。
  • 安全能力分层发布：Google 的 Gemini 3.8 Flash Cyber、Anthropic Mythos 5.1、OpenAI Astra 的 cyber 能力都采用“可信用户/受限功能/额外安全评估”的分层路径。
  • 推理成本仍是产品化关键：Anthropic 降低缓存读取成本，Google 提醒高 effort 可能带来更多 token 使用，阿里/智谱/腾讯在中国市场继续用开源和低价 API 压低试用门槛。
政策舆情
  • 美国：Axios 和 WSJ 报道显示美国政府围绕前沿模型发布前审查、G20 创新政策和版权诉讼立场形成更明确的产业政策倾向；但具体强制监管框架仍未落地。
  • 欧洲：AI 生成内容透明度代码和 AI Act 义务进入执行期，企业在欧盟面向用户分发 AI 内容时需要标识、检测、披露和下游文档链条。
  • 中国：专项治理覆盖平台内容、AI 应用、未成年人保护、仿冒真人和生成内容标识，对下游 AI 应用市场的审核成本形成持续压力。
上下游产业
  • 算力：NVIDIA 数据中心收入继续高速增长，Broadcom/Dell/Equinix 等把 AI 增长从 GPU 芯片扩展到 ASIC、服务器、网络、存储、推理交换和边缘机房。
  • 资本：a16z Machine Age Fund 的 11 亿美元硬件基金显示 VC 正把 AI 投资重心从软件应用外扩到芯片、内存、网络、机器人、电力和冷却。
  • 开源生态：Latent Space、GitHub Trending/PullRepo 显示 Agent skills、AI 工程工作台、RAG、浏览器/桌面控制和代码代理仍是开发者高热方向。
下游应用市场
  • 企业软件：Snowflake 财报相关报道显示 AI 原生数据产品开始进入收入叙事，数据平台不再只卖存储和查询，而是在卖 Agent 可调用的数据底座。
  • 网络安全：CrowdStrike 与 NVIDIA 的 SafeMind、OpenAI Astra、Google Gemini Cyber、Anthropic Mythos 共同说明安全领域已经从“用 LLM 写报告”走向攻防闭环模型。
  • 出行与机器人：Guardian 报道伦敦通过 Uber 与 Wayve 上线带安全员的自动驾驶出租车试运营；同时 Uber 在欧洲面对算法定价与劳动权益诉讼，AI 应用商业化正与监管冲突同步出现。
